# 人物显示与近战

## 当前人物：2D 纸片角色

正式配置 `source/Assets/Characters/dwarf.json` 只支持 `Renderer: sprite4`。当前身体、衣物、头发和手掌来自 `Assets/Characters/FlatPawn/`；手持工具继续复用 `Assets/Characters/Sprites4/`，头像使用同一套合成贴图。名字中的 sprite4 表示镜头相对四方向，不限定使用最初那套图集。

`DirectionalDwarfView.cs` 负责合成缓存、方向与动作；`ActorModelView.cs` 保留原调用名称，但只桥接模拟状态到 2D 显示，不再包含模型场景、骨架、AnimationPlayer、3D 装备挂载或模型回退分支。地图、相机与选取仍在三维世界中，Node3D / Sprite3D 是放置纸片角色所需的引擎节点。

人物与手持物使用模拟时间：暂停冻结动作，行走、工作、攻击、防御、搬运、卧床与倒地沿用当前行为。2D 动作是状态表现，不承诺像素轮廓与武器扫掠轨迹逐点一致。

保留的 `CompactPrototype`、`ModularDwarf`、`ModularFour` 及对应 `art/dwarf/` 目录也是 **2D** 制作与实验资源，不属于已移除的三维模型。

## 2026-10-29：移除旧 3D 人物方案

已删除旧 Dwarf / DwarfV2 / DwarfV3 / Whitebody / SwordShield 模型、旧 Blender 源文件与备份、下载模型、3D 演示与录制帧、导入缓存、三维装备网格及模型专用检查和烘焙工具。旧模型配置也已删除。没有另存一份模型副本。

普通游戏保留新 2D 资源；`Assets/Combat/` 中仍被模拟使用的数据保持原样。部分本地冻结测试快照中的旧模型副本也已移除；历史报告保留，但那些快照不再视为完整的资源备份。旧模型的开发记录可以从 Git 历史查阅；本次不改写历史。

`--actor-model-test`、`--tool-equipment-test`、`--equipment-dimensions-test` 旧模型入口已移除。`--dwarf-integration-test` 继续作为新 `--sprite-integration-test` 的兼容名称。

## 工具、武器与模拟数据

二维工具图标保存在 `Assets/Textures/Items/`，原包路径记录在该目录的 `sources.json`；`tools/import-equipment.py` 只导入二维贴图，不再创建三维模型目录。手持显示优先使用 Sprites4 的专用图，再回退到物品图标。

`Assets/Combat/equipment-geometry.json` 定义米制 Size、参考包围盒和有效接触段；`grip-poses.json` 是已保存的握持轨迹样本。这些 JSON 是模拟输入，不需要在运行时加载被删除的模型。剑、矿镐等轨迹由握持变换与接触段计算，Reach 从有效攻击轨迹包络推导。调整数值需要重新验证判定，不能把纸片缩放当作碰撞尺寸变更。

近战仍包括起手、有效挥击、收招、附近空间查询、身体简化形状、墙体阻挡、面向盾挡、限时招架、体力与破防。取消命令、换武器或失能会终止攻击。只有物品表中启用的装备可实际使用；预留武器模板不等于已加入配方。

ItemProperties 的材质、品质和耐久字段随合堆、拆分、搬运和存读档保留。角色换成 2D 不改变这些规则，也不删除对应模拟检查。

## 无窗口验证

- `tools/check.sh` 默认使用 `--headless`，包含当前人物的 `--sprite-integration-test`：外观读档、工具图、换装、镜头方向、暂停、攻击及实际移动。
- `tools/navigation-check.sh --melee-checks`：武器扫掠、墙体、盾挡、招架、取消、存档与时间步长。
- `tools/navigation-check.sh --equipment-dimensions-checks`：尺寸影响判定范围、接触段、物品属性和物流持久化。
- `--melee-test` 是可选的当前纸片人物画面检查；不会由本次清理启动。

之前的 FPS 数据来自更早的冻结角色场景，不能当作当前 FlatPawn 人物性能结论。渲染压测继续保持暂停。
