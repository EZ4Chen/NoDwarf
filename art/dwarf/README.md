# 低模矮人样板

原创程序化低模资源，使用 Blender 5.2.3 制作；无外部模型、插件或下载素材。

## 文件与预览

- `dwarf.blend`：可编辑源文件，默认展示内衣内裤基础身与胡须。Idle 动作已激活，可以播放时间轴。
- `build_dwarf.py`：完整可重建的建模、绑定、动作和 GLB 导出脚本。
- `../../source/Assets/Characters/Dwarf/`：Godot 资源与 `manifest.json`。
- `../../source/Scenes/CharacterLab/DwarfLab.tscn`：独立换装预览。可逐件穿脱、切换动作、暂停和转身查看。
- `../../source/.local/dwarf-lab/`：引擎截图和自动验证报告（本地输出，不入库）。
- `lineup.png`、`animation-preview.mp4`、`validation.json`：本次交付的引擎实拍合照、动作视频和验证快照。

从仓库根目录启动预览：

```bash
bash source/tools/run.sh res://Scenes/CharacterLab/DwarfLab.tscn
```

运行导入后的专项验证（会截图并退出）：

```bash
bash source/tools/run.sh --resolution 1280x900 res://Scenes/CharacterLab/DwarfLab.tscn -- --dwarf-lab-test
```

重新生成资源和 Blender 渲染：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python art/dwarf/build_dwarf.py
```

只重新生成模型和导出，不渲染：在上述命令末尾加 `-- --skip-render`。生成会覆盖本目录的 `.blend`、PNG 和本样板的 GLB；在 Blender 手工修改后，请先另存副本。

## 资源拆分

基础身的米白色背心与内裤属于基础身体，不是可脱卸装备。胡须是独立外观件，可以隐藏；没有头发、头盔、靴子或武器混进基础身。

外衣、长裤、靴子、皮甲、铁盔分别是共用同一骨架规范的蒙皮装备。皮甲包含皮袖和金属肩甲，与外衣占用同一上身槽。镐、剑、盾是独立静态网格，原点已转换到装备挂点的局部坐标；不要再增加人工握柄偏移。

四套预览方案：基础身、日常衣着、矿工、守卫。右手镐与剑互斥；左手盾独立。`DwarfModel.gd` 按骨骼名称重映射装备蒙皮，换装不会创建第二套活动骨架。

为避免身体穿出衣物，提供七种覆盖区域组合 `body_mask_ABC.glb`：A 为上身，B 为长裤，C 为靴子，1 表示隐藏被装备覆盖的身体面。穿脱任何一件都会选择对应身体网格；脱光装备回到包含完整内衣内裤的 `dwarf_base.glb`。

## 骨架与动作

米制单位，基础身约 1.60 米，戴盔约 1.625 米。Blender 中 Z 向上、角色朝 -Y；导入 Godot 后 Y 向上、角色朝 +Z。

23 根骨骼包括 18 根身体/根骨骼和 5 个挂点：

| 挂点 | 用途 |
| --- | --- |
| `slot_hand_r` | 镐、单手剑 |
| `slot_hand_l` | 盾、左手道具 |
| `slot_head` | 后续头部附件 |
| `slot_back` | 后续背包等附件 |
| `slot_belt` | 后续腰间附件 |

Idle（2 秒）、Walk（1 秒）、Mine（1.5 秒）、Attack（1 秒）和 Carry（1 秒），24 fps 制作。Attack 是单次动作，其余循环。动作全部原地播放，实际位移留给游戏寻路。Mine 是单手镐动作，Carry 目前是空手搬运姿势；未制作双手镐、双手武器、跳跃、攀爬、受伤和死亡动作，也未接入游戏攻击命中时刻。

蒙皮和动作针对本样板体型。大幅改变四肢比例或更换外部模型，仍需要检查绑定与穿模，不能仅凭骨骼同名保证适配。

## 材质与验证范围

使用不透明顶点色与共享的哑光/金属两种材质，不需要贴图。模型按装备槽合并，保留装备独立开关。`DwarfImport.gd` 修正 Godot 导入时的顶点色开关并开启背面剔除；各 GLB 的 `.import` 文件应随资源保留。

专项验证覆盖四套穿戴 × 五种动画 × 六个时刻、九件外观/装备逐件穿脱、五个挂点的动态位置、动作实际运动、循环首尾和原地根骨骼。另将五个关键姿势的骨骼位置与 Blender 原始姿势对照，检查导出后的动作是否保持一致。保存前侧后视图与采矿、挥剑、搬运姿势截图供视觉检查。有限采样不等同于所有帧或任意新装备的无穿模保证。

这是独立资源样板；尚未替换主游戏的纸片居民，也未做完整地图百人压力测试。不要用预览场景的表现推断全地图帧率。

本次实际导入统计（均包含胡须）：基础身 2,748 三角形 / 2 表面，日常 2,896 / 8，矿工 3,268 / 11，守卫 3,808 / 13。120 个动画采样与 600 次挂点位置检查通过，关键制作帧与 Blender 源姿势的骨骼位置最大误差约 4.6 毫米。
