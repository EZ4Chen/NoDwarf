# 2D 人物制作资源

当前人物使用 FlatPawn 纸片方案；三维模型、Blender 工作文件、下载候选模型和旧 3D 录制素材已于 2026-10-29 清理。

- `flat-pawn-five/`：当前五种纸片体型与外观部件的源图、检查图和生成记录。
- `flat-pawn-study/`：二维比例草案。
- `sprites4/`：四方向图集、手持工具与服装原始素材；部分手持物仍被正式游戏复用。
- `compact-prototype/`、`modular-dwarf/`、`modular-four/`：二维比例、分层与换装实验，保留源图和制作脚本。

正式资源在 `source/Assets/Characters/FlatPawn/` 和 `Sprites4/`；状态接入与战斗数据说明见 [人物显示与近战](../../docs/3D人物与剑盾近战.md)。
