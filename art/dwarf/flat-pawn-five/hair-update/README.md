# 发型覆盖与独立配色

使用内置 image_gen 生成，完整提示词在 `generation.json`。

- 新增短寸、短卷发、马尾、发髻；连同侧分短发、蓬松长发、双辫，共七款发型，另有光头。
- 三种脸型分别带对齐原始头部锚点的发根覆盖图，修复侧面后脑勺裸露。发根与发型统一染色；光头、帽子和头盔不会显示发根。
- 发色、肤色、胡须颜色使用独立字段，支持预设或自定义 `#rrggbb`。旧档缺少胡须颜色时默认银灰。
- 肤色只作用于皮肤填色，保留内衣、眼睛、眉毛和描边。手部同步肤色。头发和胡须使用独立调色，深色描边保留。
- 外观编辑器加入三个颜色选择器和四方向预览；保存后同步头像与场景角色。

`HairPaletteReview.tscn` 使用游戏实际合成器展示所有发型和颜色，带交互式颜色选择器。添加 `--capture-hair` 可输出 `styles-review.png` 和 `palettes-review.png`，并运行颜色存档、颜色独立性、内衣保护、三种头型后脑覆盖和左右镜像检查。

原图、运行时贴图的重新打包仍由上一级 `pack.gd` 完成。
